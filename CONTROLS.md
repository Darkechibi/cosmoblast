# CosmoBlast controls

## In-game (updated)
Push a **direction to shoot that way** (Space Zap style).  
**A / Space / Fire** also shoots in the current aim direction.

| Input | Action |
|--------|--------|
| Stick / D-pad / Arrows / WASD | Aim + shoot that direction |
| A / Space / Left Ctrl | Start game + shoot |
| Face buttons (backup): Y up, B right, X left, LB down | Aim + shoot |
| F2 | Reset |

## If directions still fail
1. Click the Stella window  
2. Try **arrow keys** or **WASD** (proves the ROM is fine)  
3. Tab → Input Settings → Event Mapping → map Left Joystick Up/Down/Left/Right while wiggling your stick/D-pad
